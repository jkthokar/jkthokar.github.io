출고파일 자동 생성

채널마다 다른 발주서 양식을 읽어, 우리 회사 출고 양식 그대로 브랜드별 파일을 만듭니다. Windows 프로그램으로 설치해 씁니다.

  • 입력
    쿠팡 · B마트 · 컬리 발주서, 소비기한 가이드, 입고확인서 PDF
  • 결과
    브랜드별 출고파일 · 합계수량표 · 파렛트 구성 · 센터별 박스 라벨(HWP) · 입고분 합계
  • 발주 합계 = 출고파일 합계 = 합계수량표
  • 발주서 소비기한을 가이드와 대조
  • 입고확인서 PDF와 상품 · 수량 대조
  • 한국어 / English 화면 전환

발주 정리

여러 쇼핑몰 주문 엑셀을 끌어다 놓으면 발주 · 택배 · 집계 · 출력용 시트를 한 번에 만듭니다. 설치 없이 브라우저에서 바로 씁니다.

  • 입력
    쇼핑몰별 주문 엑셀 여러 개
  • 결과
    발주 · 택배(같은 받는 분 묶음) · 품목×중량 집계 · 출력용 · 확인사항
  • "1Kg"와 "1kg" 같은 표기 차이를 한 상품으로 통일
  • 상품명 속 탭 · 겹친 공백 정리
  • 원본 주문 합계 = 집계 합계 확인

급여 정산

지문 근태기 파일을 넣으면 회사 규칙대로 근무시간 · 식대 · 근무비를 계산하고, 손으로 만들던 근무일지와 같은 모양의 엑셀을 만듭니다.

  • 입력
    지문 근태 엑셀 (오른손 R · 왼손 L 기록), 직원명단
  • 결과
    근무비지급요청 · 전체 근무일지 · 공장별 요약 · 개인별 명세서
  • R · L 두 손가락 기록을 한 사람으로 합침
  • 입사 1년 시급 인상은 승인한 뒤에만 적용
  • 출근 · 퇴근 누락은 그날을 표시해 수정 요청

재고 관리

입고 · 생산 사용 · 판매를 기록하면 품목별 현재고와 부족 품목, 소비기한이 가까운 재고를 바로 보여 줍니다.

  • 입력
    입고 · 사용 · 판매 기록 (화면 입력 또는 엑셀)
  • 결과
    현재고 · 최소재고 미달 · 소비기한 임박 · 이동 기록 엑셀
  • 재고보다 많이 출고하면 저장 전에 막음
  • 최소재고 아래로 내려가면 빨간 표시
  • 소비기한 30일 이내 재고 표시
냉장 창고 · 8개 품목예시 데이터

틀린 파일은 만들지 않습니다

자동화의 핵심은 속도보다 검증입니다. 발주 · 출고 · 급여 업무에서 흔히 생기는 실수마다 검사를 하나씩 넣었습니다.

TOTAL CHECK합계가 다르면 멈춤

발주서 합계, 출고파일 합계, 합계수량표 합계를 비교합니다. 하나라도 다르면 빨간 "검증 실패"로 표시합니다.

EXPIRY GUIDE소비기한 가이드 대조

발주서에 적힌 소비기한이 이번 주 가이드와 다르면 해당 칸을 빨간색으로 표시하고 파일을 만들지 않습니다.

PDF MATCH입고확인서 PDF 대조

채널에서 받은 입고확인서 · 거래명세서의 상품, 수량, 박스를 발주서와 한 줄씩 맞춰 봅니다. 여러 쪽짜리도 읽습니다.

NAME RULES상품명 표기 통일

"1Kg"와 "1kg", 띄어쓰기 차이처럼 엑셀이 두 번 세는 표기를 한 상품으로 묶고 확인사항에 남깁니다.

APPROVAL사람이 승인하는 변경

시급 인상, 새 상품 등록처럼 돈과 기준이 바뀌는 일은 자동으로 적용하지 않고 담당자 확인을 받습니다.

YOUR FORMAT회사 양식 그대로

결과 파일은 지금 쓰는 엑셀 · 한글 양식을 복사해 만듭니다. 직원이 새 양식을 배울 필요가 없습니다.

도입은 이렇게 진행합니다

회사마다 발주서 · 출고 양식 · 급여 규칙이 다르므로, 귀사의 파일과 규칙에 맞춰 만들어 드립니다.

  1. STEP 1현재 파일 받기

    지금 쓰는 발주서 · 출고 양식 · 근태 파일 · 재고 장부 샘플을 받습니다.

  2. STEP 2규칙 맞추기

    상품명 규칙, 박스 입수, 급여 규칙, 양식 위치를 회사에 맞게 설정합니다.

  3. STEP 3나란히 검증

    한 달 동안 기존 방식과 결과를 비교해 숫자가 같은지 확인합니다.

  4. STEP 4설치 · 교육

    Windows 프로그램 설치, 사용 설명서(한국어 · English), 담당자 교육.
