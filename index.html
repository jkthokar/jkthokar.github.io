Smart ATM

2026 · Computer vision, IoT

Access control and a tamper alarm for ATM booths. The machine unlocks only after a clearly visible face is confirmed across several frames in a row; covered faces are always refused, and a vibration sensor or phone can set off a siren the moment someone tries to break in.

Built with MobileNetV2, OpenCV DNN, TensorFlow, ESP32, Python, pytest and GitHub Actions

Source code

Smart Attendance System

2026 · Deep Learning, Group 11

Takes attendance from a live webcam at the classroom door, or from a single group photo. VGG-Face embeddings, MTCNN detection and an SVM classifier reach 95.2% accuracy on held-out test data, and absent students are emailed automatically after each session.

Being prepared for publication, with a larger dataset, an ablation study and a formal ethics section.

Built with VGG-Face, MTCNN, scikit-learn, OpenCV, Python

Source code

Smart Blind Stick

2026 · Embedded systems, with Prof. Nur Alam

An assistive cane for visually impaired users. Three ultrasonic sensors and a water sensor warn of obstacles and puddles through vibration and sound. If the user falls or gets stuck, the stick sounds an SOS on its own and sends a caregiver a GPS map link over Telegram.

A journal paper, presentation and demo video are in progress.

Built with Arduino UNO R4 WiFi, C++, NEO-6M GPS, Telegram

Source code

Built with MediaPipe, OpenCV, Python
